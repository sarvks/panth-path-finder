LOVABLE MASTER BUILD PROMPT

Sikhism — An Interactive, Animated Knowledge Universe

Build a production-quality, highly visual, deeply educational website dedicated to Sikhism, inspired structurally by:

buddhism.mahakalistudios.com

siva.mahakalistudios.com

shakti.mahakalistudios.com

The website should aspire to become a comprehensive digital introduction, encyclopedia, learning environment, cultural archive, and visual exploration of Sikhism.

This is NOT merely a blog.

It should feel like entering an interactive Sikh knowledge universe.

The experience should combine:

Sacred philosophy × history × scripture × poetry × music × ethics × culture × scholarship × interactive learning × cinematic web design.

1. PRODUCT VISION

Create a website capable of taking someone from:

“I know nothing about Sikhism.”

to:

“I understand its history, philosophy, scripture, practices, institutions, diversity, culture, debates, and contemporary global presence.”

Design the information architecture so that thousands of future articles, illustrations, animations, timelines, maps, audio recordings, primary-source excerpts, quizzes, and scholarly references can eventually be added without redesigning the website.

The website must distinguish clearly between:

Sikh scripture

Sikh tradition

historical evidence

theological interpretation

community practice

academic scholarship

contested historical claims

contemporary opinion

Never present disputed interpretations as universally accepted Sikh doctrine.

2. VISUAL DIRECTION

Create a visual language completely distinct from generic “religious website” aesthetics.

Think:

Punjab × manuscript illumination × Nishan Sahib × architecture × calligraphy × poetry × sacred music × modern editorial design × cinematic storytelling.

Use a sophisticated palette influenced by:

deep midnight blue

warm saffron

ivory

parchment

charcoal

muted gold

Avoid excessive gold, kitschy temple aesthetics, generic spirituality imagery, and stock-photo-heavy layouts.

Typography should combine strong contemporary editorial typography with excellent support for:

English + Gurmukhi/Punjabi.

Gurmukhi should be treated as a major visual component of the website rather than an ornamental afterthought.

66. PRODUCT STANDARD

The final website should NOT resemble:

a generic Wikipedia clone
a temple website
a religious recruitment website
a basic blog
a collection of AI-generated cards

It should feel like a new form of digital scholarship.

Think of the conceptual combination of:

an encyclopedia + museum + atlas + language laboratory + music archive + documentary + university course + interactive knowledge graph.

It must be intellectually serious enough for researchers while remaining understandable to someone encountering Sikhism for the first time.
